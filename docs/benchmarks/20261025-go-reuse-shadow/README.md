# Go producer-authentication shadow

The private prototype now identifies clean native Go edit results that match an
independent fresh parse, while **keeping the fresh verifier active**. Two
chained insertions on Cognociente's original 140,368-byte source produce two
would-certify observations and two real verifier observations. Native incoming
and fresh trees match structure, states and internal precedence. This is a
correctness qualification step, not a new speed result or permission to bypass
verification. Runtime, ledger, admission and main merges remain unchanged.

The exact Go9ad artifact grants a generic capability through runtime profiles;
engine code does not branch on the language name. Actual default DFA ownership,
source identity, fresh scheduling policy and complete read history remain
separate requirements. Every new small-source schedule, alias and frontier
choice is capability-gated. Copy, transformed `+`→`-` factories, identity
wrappers, actual compact producers and absent capabilities must not certify.
This qualifies the default native producer only; compact-produced old trees
still need an independent producer contract.

## Preserved failure and identical baseline control

V1's strict compact-origin negative fails on an internal precedence comparison.
The identical control is then run on canonical baseline, candidate and a
candidate differing only by the Go capability being off. All three preserve the
same failure: **7,037 internal dynamic-precedence differences**, zero ParseState
or PreGotoState differences, identical whole-tree state hashes and exact fresh
public structure. Native-origin controls match every plane in every arm.
The original failed assertions and logs remain archived; this difference is not
repaired or relabeled as a passing strict-fresh comparison.

After that causal proof, test-only V2 requires unsupported compact results to
match the complete capability-off cross-producer result and independent fresh
public structure, with no small mode, native producer key or would-certify grant.
Every native would-certify comparison still requires absolute fresh structure,
state and precedence equality. No native assertion or runtime rule is weakened.

Complete-operation attribution, all 410 non-Go rows, wider clean/edit negative

performance win, compact-producer certification or graduation is claimed here.
