## Banked outcomes

- **External-scanner reuse is broader and safer.** SQL checkpoint state and
  PowerShell's stateless scanner are certified for changed-edit reuse. Python
  scanner checkpoints are explicit. Unproven stateful scanners still fail
  closed.
- **Incremental ownership is more explicit.** Dirty-span, edit-boundary, and
  parser-frontier checks are stricter; collapsed named-leaf behavior has moved
  into exact native ownership for registered artifacts. Unsupported adapted
  artifacts fail closed instead of relying on a generic reconstruction walk.
- **Repository work is more inspectable.** The repository map names ownership
  seams, artifact cleanup preserves durable run receipts, issue intake is
  structured, and the root race gate is sharded with partial JSON artifacts
  salvaged on failure or timeout.
