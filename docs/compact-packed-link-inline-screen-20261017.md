# Direct packed-link decoding screen — 2026-10-17

**Rejected: compact throughput still regresses.** The default compiler build reports
22 inline decoder expansions, but compact Go slows 3.74–4.13% and
owned YAML slows 1.43–1.91% against qualified runtime
`5e52cf2a2644f3d38785513eebc39f8cf8a506b2`. No engine, route, allowlist or
ledger baseline changes are promoted.

This follows the [first packed-storage rejection](compact-packed-link-storage-screen-20261017.md).
It preserves its 16-byte main records, full-width cold metadata, logical IDs,
rollback/reset/retention, byte accounting and clone isolation. An initial
smaller accessor still costs 106 against an inlining budget of 80. That
unmeasured accessor is replaced by direct inline decoding after the existing
range proofs. Full-width lookups keep the same binding checks and error
propagation. The 22 reported expansions comprise 20 direct reads, the checked
accessor and an autogenerated method wrapper; the source also has two
diagnostic-only direct reads. Append encodes the zero-score case directly and handles other
metadata through a helper.

## Measurements

Positive values are slower. Each comparison is against the qualified runtime;
percentages from the two packed-storage experiments are not combined.

| Workload | Time direction and p |
| --- | ---: |
| Go R4 | +3.95% (p<.001) |
| Go rewrite | +4.13% (p<.001) |
| Go query | +3.74% (p<.001) |
| Go language | +4.12% (p<.001) |
| Go large | +4.02% (p<.001) |
| Ordinary YAML attempt + fallback | -0.44% (p=0.989) |
| Owned YAML R4 | +1.43% (p=0.046) |
| Owned YAML 8 KiB | +1.91% (p=0.004) |

All five compact Go differences have p<.001. Owned YAML R4 has p=.046 and the
8 KiB stream p=.004. Ordinary YAML's -0.44% direction is inconclusive
(p=.989). Its allocated bytes fall **15,608→14,072 B/op (-9.84%, p<.001)**,
with unchanged allocation count. That saving does not justify the supported
compact-path regressions. All other byte medians are exact except a three-byte
Go-language rounding movement; all allocation counts are exact. No RSS or
retained-memory saving is claimed.

Default Go full/edit/no-edit directions are **-0.16% / +0.21% / +1.42%**
(p=.678 / .208 / .020). Only no-edit is supported; these controls remain
unattributed. No-edit stays **0 B/op / zero allocations**.
